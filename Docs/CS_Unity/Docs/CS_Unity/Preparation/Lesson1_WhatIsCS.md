## 🎯 **Что такое C# и Скрипты?**
**C#** (произносится "Си Шарп") — это язык программирования, простой и мощный, на котором пишут игры в Unity. Представь: ты даёшь инструкции компьютеру, как "покажи сообщение" или "двигай героя". **Скрипт** — это файл с такими инструкциями (расширение .cs), который прикрепляется к объектам в игре. Без скриптов твоя арена — просто картинка, с ними — герой бегает, враги атакуют!

*Ссылка на официальную документацию*: [C# in Unity](https://docs.unity3d.com/Manual/CSharpCompiler.html).

## 🔄 **Зачем это Нужно? (Создание, Использование)**
C# и скрипты — основа любой игры в Unity. Они позволяют добавлять логику: движение, стрельбу, подсчёт очков. В твоём топ-даун шутере скрипты будут управлять героем, пулями и врагами. Этот урок — база: ты напишешь простой скрипт, чтобы увидеть, как код оживает в консоли. Освоишь это — и сможешь создавать сложные механики!

**Преимущества**:  
- Легко менять: Измени код — игра меняется.  
- Практика: Видишь результат сразу, мотивирует.  

**Распространённые Ошибки**:  
- Неправильное имя скрипта (должно совпадать с class).  
- Забыл сохранить код перед Play.  

## ⚙️ **Шаг за шагом: Создаём первый скрипт**
SO наследуют ScriptableObject: создай файл-ассет, редактируй поля.  

1. **Открой Unity и свой проект.**  
   Убедись, что у тебя установлен Unity 2022.3+ LTS и создан проект шутера (смотри [Установка Unity Hub и Editor](../../Preparation/Install.md)).  

2. **Создай новый скрипт:**  
   - В окне **Project** (внизу Unity) найди папку `Assets`.  
   - Щёлкни правой кнопкой мыши > **Create** > **C# Script**.  
   - Назови скрипт `HelloGame` (без пробелов, пиши слитно).  

3. **Открой скрипт:**  
   - Дважды щёлкни по файлу `HelloGame` в папке `Assets`.  
   - Откроется редактор кода (Visual Studio или VS Code). Ты увидишь такой шаблон:  
     ```csharp
     using System.Collections;
     using System.Collections.Generic;
     using UnityEngine;

     public class HelloGame : MonoBehaviour
     {
         // Start is called before the first frame update
         void Start()
         {
             
         }

         // Update is called once per frame
         void Update()
         {
             
         }
     }
     ```
     - `using UnityEngine;` — подключает инструменты Unity, чтобы твой код работал с игрой.  
     - `public class HelloGame : MonoBehaviour` — это твой скрипт, который Unity может прикрепить к объектам.  
     - `void Start()` — функция, которая запускается один раз, когда объект с этим скриптом появляется в игре.  
     - `void Update()` — функция, которая запускается каждый кадр (много раз в секунду).  

4. **Добавь код для вывода сообщения:**  
   - Внутри функции `Start()` напиши:  
     ```csharp
     Debug.Log("Привет, это мой шутер!");
     ```
   - Твой код теперь выглядит так:  
     ```csharp
     using System.Collections;
     using System.Collections.Generic;
     using UnityEngine;

     public class HelloGame : MonoBehaviour
     {
         void Start()
         {
             Debug.Log("Привет, это мой шутер!");
         }

         void Update()
         {
         }
     }
     ```

5. **Сохрани код:**  
   - Нажми **Ctrl+S** (или **File > Save** в редакторе кода).  
   - Вернись в Unity — скрипт обновится автоматически.

6. **Прикрепи скрипт к объекту:**  
   - В окне **Hierarchy** (слева в Unity) щёлкни правой кнопкой > **Create Empty** и назови объект `TestObject`.  
   - Перетащи файл `HelloGame` из папки `Assets` на `TestObject` в **Hierarchy** (или в **Inspector** выбери **Add Component** > напиши `HelloGame` > выбери скрипт).  

7. **Запусти игру и проверь:**  
   - Нажми кнопку **Play** (▶️) вверху Unity.  
   - Открой вкладку **Console** (Window > General > Console).  
   - Ты увидишь сообщение: **"Привет, это мой шутер!"**. Это твой код сработал! 🎉  

*Ссылка на документацию*: [Debug.Log](https://docs.unity3d.com/ScriptReference/Debug.Log.html).

## 💻 **Что ты увидишь?**
В окне **Console** появится строка "Привет, это мой шутер!". Это значит, что Unity выполнил твой код, и ты успешно дал первую команду игре. Поздравляю, ты теперь кодер! 😎

## 🔄 **Советы**
- **Ошибки?** Если в консоли ничего не появилось, проверь:  
  - Сохранил ли ты код (Ctrl+S)?  
  - Прикреплён ли скрипт `HelloGame` к объекту `TestObject`?  
  - Нет ли красных ошибок в консоли? Если есть, перепроверь код на опечатки.  
- **Хочешь больше?** Попробуй добавить `Debug.Log` в функцию `Update()`. Что произойдёт? (Подсказка: сообщение будет появляться каждый кадр, то есть много раз!)  

## ⚙️ **Зачем это пригодится в твоём шутере?**
Функция `Debug.Log` помогает проверять, работает ли твой код, и находить ошибки. В будущем ты будешь использовать её, чтобы, например, выводить количество здоровья героя или проверять, попала ли пуля во врага. Этот урок — твой первый шаг к управлению игрой!
