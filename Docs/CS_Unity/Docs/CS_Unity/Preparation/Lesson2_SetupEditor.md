
# 🎮 Настройка Unity и Редактора Кода

Привет, юный кодер! 💻 В этом уроке ты настроишь Unity и редактор кода, чтобы начать писать скрипты для твоего топ-даун шутера (*UnityTopDownShooterQuest*). Мы установим Unity Hub, создадим проект и подключим редактор кода (Visual Studio или VS Code), чтобы ты мог писать C# без проблем. Это как подготовка арены перед битвой — всё должно быть готово! Время на урок: 15–20 минут.  

**Что тебе понадобится?**  
- Компьютер с Windows, macOS или Linux.  
- Интернет для скачивания Unity Hub.  
- Папка для хранения проекта (например, `C:\MyGames\`).  

**Предупреждение**: Убедись, что у тебя достаточно места на диске (Unity требует ~10 ГБ). Если редактор кода не открывается, проверь настройки Unity. Тестируй проект в Play Mode, чтобы убедиться, что всё работает.  

Готов настроить свой кодерский арсенал? По шагам, как по уровням! 📝

## 🎯 **Что такое Unity и Редактор Кода?**
**Unity** — это движок для создания игр, где ты собираешь сцены, объекты и пишешь код. **Редактор кода** (Visual Studio или VS Code) — это программа, где ты пишешь скрипты на C#, чтобы управлять игрой. Без правильной настройки Unity и редактора кодить будет сложно, как сражаться без оружия!

*Ссылка на официальную документацию*: [Getting Started with Unity](https://docs.unity3d.com/Manual/GettingStarted.html).

## 🔄 **Зачем это Нужно?**
Настройка Unity и редактора кода — это фундамент твоей работы. Ты создашь проект, где будешь строить шутер, и настроишь редактор, чтобы писать код удобно, с подсветкой ошибок и автодополнением. В этом уроке ты запустишь Unity, создашь пустой проект и убедишься, что редактор кода готов к бою!

**Преимущества**:  
- Быстрая настройка: Один раз настроил — пиши код без проблем.  
- Удобство: Редактор подсказывает команды, экономит время.  

**Распространённые Ошибки**:  
- Неправильная версия Unity (нужен 2022.3+ LTS).  
- Редактор не установлен или не связан с Unity.  

## ⚙️ **Шаг за шагом: Настройка Unity и Редактора Кода**

1. **Установи Unity Hub:**  
   - Перейди на [официальный сайт Unity](https://unity.com/download).  
   - Скачай и установи **Unity Hub** — это центр управления проектами и версиями Unity.  
   - Запусти Unity Hub, войди в аккаунт (создай бесплатный, если нет).  

2. **Установи Unity Editor:**  
   - В Unity Hub нажми **Installs** > **Install Editor**.  
   - Выбери версию **2022.3+ LTS** (LTS — стабильная, для долгосрочных проектов).  
   - В установке отметь:  
     - **Visual Studio Community** (или VS Code, если предпочитаешь).  
     - **Windows Build Support** (или macOS/Linux, в зависимости от системы).  
   - Дождись установки (~5–10 ГБ, зависит от модулей).  

3. **Создай новый проект:**  
   - В Unity Hub нажми **Projects** > **New Project**.  
   - Выбери шаблон **3D** (для топ-даун шутера).  
   - Назови проект `UnityTopDownShooterQuest`.  
   - Выбери папку для проекта (например, `C:\MyGames\UnityTopDownShooterQuest`).  
   - Нажми **Create Project** — Unity откроет твой проект.  

4. **Проверь редактор кода:**  
   - В Unity перейди в **Edit** > **Preferences** (Windows) или **Unity** > **Preferences** (macOS).  
   - В разделе **External Tools** убедись, что выбран **Visual Studio** или **VS Code** как **External Script Editor**.  
   - Если редактор не указан, нажми **Browse** и выбери исполняемый файл (например, `C:\Program Files\Microsoft Visual Studio\...\devenv.exe`).  

5. **Создай тестовый скрипт для проверки:**  
   - В окне **Project** найди папку `Assets`.  
   - Щёлкни правой кнопкой > **Create** > **C# Script**, назови `TestSetup`.  
   - Дважды щёлкни по `TestSetup` — должен открыться Visual Studio или VS Code.  
   - В открывшемся редакторе ты увидишь:  
     ```csharp
     using System.Collections;
     using System.Collections.Generic;
     using UnityEngine;

     public class TestSetup : MonoBehaviour
     {
         // Start is called before the first frame update
         void Start()
         {
             
         }

         // Update is called once per frame
         void Update()
         {
             
         }
     }
     ```
   - В `Start()` добавь:  
     ```csharp
     Debug.Log("Редактор кода работает!");
     ```

6. **Протестируй в Unity:**  
   - Сохрани код (**Ctrl+S**).  
   - В Unity создай пустой объект: **Hierarchy** > правой кнопкой > **Create Empty**, назови `TestObject`.  
   - Перетащи скрипт `TestSetup` на `TestObject` (или **Add Component** > `TestSetup`).  
   - Нажми **Play** (▶️) и открой **Console** (Window > General > Console).  
   - Увидишь сообщение: **"Редактор кода работает!"**. Это значит, всё настроено! 🎉  

*Ссылка на документацию*: [Setting Up Visual Studio](https://docs.unity3d.com/Manual/VisualStudioIntegration.html).

## 💻 **Что ты увидишь?**
- Unity Hub: Удобный интерфейс с твоими проектами.  
- Unity Editor: Окно с **Scene**, **Hierarchy**, **Project**, **Inspector** и **Console**.  
- Редактор кода: Открывает .cs файлы с подсветкой синтаксиса.  
- В консоли: Сообщение "Редактор кода работает!" после запуска.  

## 💡 **Задание: Попробуй сам!**
1. Измени сообщение в `Debug.Log` на своё, например:  
   ```csharp
   Debug.Log("Мой шутер начинается!");
   ```  
2. Сохрани, вернись в Unity, нажми **Play** и проверь консоль.  
3. (Бонус) Создай ещё один скрипт, назови `MyGame`, добавь `Debug.Log("Я готов к кодингу!")`, прикрепи к новому объекту и проверь в консоли.  

## 🔄 **Советы**
- **Ошибки?** Если консоль пустая или редактор не открывается:  
  - Проверь, сохранён ли код (**Ctrl+S**).  
  - Убедись, что скрипт прикреплён к объекту в **Hierarchy**.  
  - В **Preferences** проверь, правильно ли выбран редактор кода.  
  - Если красные ошибки в консоли, перепроверь имя класса (должно совпадать с именем файла).  
- **Хочешь больше?** Попробуй добавить `Debug.Log` в `Update()` — увидишь, как сообщения сыпятся каждый кадр!  

## ⚙️ **Зачем это пригодится в твоём шутере?**
Настроенный Unity и редактор кода — твоя база для создания игры. Без них ты не сможешь писать скрипты для движения героя, стрельбы или взрывов. Этот урок готовит тебя к реальной разработке, где ты будешь открывать Unity, писать код и сразу видеть результат!
