# 🧪 Урок 9: Тестирование Битвы — Сборка, Баги и Баланс Огня

Привет, тест-пилот! 🧪 В этом уроке мы соберём твой топ-даун шутер в исполняемый файл (.exe), отладим баги (проверим пули, спавн, UI), и сбалансируем огонь (урон, скорость волн). Это этап полировки — игра станет playable и fun! Свяжем всё из предыдущих уроков. Время: 25–40 минут.  

**Что тебе понадобится?**  
- Открытый проект "MyTopDownShooter" с эффектами из Урока 8.  
- Компьютер для запуска .exe (не на мобильном).  

**Предупреждение**: Сборка может занять 5–10 мин. Если баги критичны — используй Console для логов. Тестируй на другом ПК для реализма!  

Готов к огневому тесту? По шагам, как по чек-листу! 📝

## Шаг 1: Собери Проект в Исполняемый Файл — Готовый Шутер для Запуска 📦
Сборка — это "пакет" игры для друзей.  

1. В Unity: **File > Build Settings**.  
2. Выбери платформу: **PC, Mac & Linux Standalone** (если Windows). Кликни **Switch Platform** (может перестроить 2–5 мин).  
3. Добавь сцену: Перетащи "Level1_Arena" (твою сцену) в Scenes in Build.  
4. Кликни **Player Settings** (иконка шестерёнки):  
   - Company Name: "DGGelik Games".  
   - Product Name: "MEGA Shooter".  
   - Default Icon: Выбери иконку (опционально, из Assets).  
5. Кликни **Build** → Выбери папку (например, Desktop/MyShooterBuild) → Назови "MEGA_Shooter.exe". Жди сборку.  

**Готово!** В папке — .exe файл и Data папка. Запусти .exe — игра работает!  
*Ссылка на помощь*: [Build Settings](https://docs.unity3d.com/Manual/BuildSettings.html).  

## Шаг 2: Отладь Баги — Поиск и Фикс Проблем (Console и Тесты) 🐛
Баги — враги разработчика: проверим стрельбу, спавн, UI.  

1. В Unity открой **Console** (Window > General > Console).  
2. Добавь логи в скрипты (например, в PlayerMovement Update()):  
   ```
   Debug.Log("Player moved: " + transform.position);  // Тест движения
   ```  
3. Кликни **Play**.  
   - Тестируй: Движение? Стрельба? Враги спавнятся? HUD обновляется? Звуки/частицы?  
   - Ошибки в Console (красные): Кликни на них — Unity покажет строку. Фикс: Например, NullReference — проверь ссылки на prefab.  
4. Общие баги:  
   - Пули не летят: Проверь velocity в BulletDamage.  
   - Враги не двигаются: Убедись Tag "Player" на герое.  
   - UI не видно: Проверь Canvas Render Mode.  
5. Собери заново после фиксов.  

**Готово!** Игра стабильна — баги побеждены.  
*Ссылка на помощь*: [Debugging в Unity](https://docs.unity3d.com/Manual/Debugging.html).  

## Шаг 3: Сбалансируй Огонь — Настрой Урон, Скорость и Волны ⚖️
Баланс — чтобы игра была challenging, но не frustrating.  

1. В скрипте PlayerMovement: bulletSpeed = 25f (быстрее пули). Damage в BulletDamage = 15 (больше урон).  
2. В EnemySpawner: waveSize = 5 (больше врагов), spawnDelay = 1.5f (быстрее волны).  
3. В EnemyHealth: maxHealth = 30 (враги слабее для начала).  
4. В UIHealthManager: Добавь вызовы (например, в BulletDamage при попадании в героя: UIHealthManager.instance.UpdateHealth(-10); — создай singleton).  
5. Прототипи: Play, запусти волну — герой выживает? Слишком легко/сложно? Твичь числа (урон +10%, скорость -20%) и пересобери.  

**Готово!** Баланс — как идеальный залп.  
*Ссылка на помощь*: [Баланс в Геймдизайне](https://docs.unity3d.com/Manual/BestPracticeUnderstandingPerformanceInUnity.html).  

## Шаг 4: Сохрани и Протестируй Сборку — Финальный Рун ▶️
Проверим .exe в деле.  

1. Сохрани сцену и скрипты: **File > Save** (Ctrl+S).  
2. Собери заново: Build Settings > Build.  
3. Запусти .exe на твоём ПК или другом:  
   - Движение, стрельба, спавн? Баги? Баланс fun?  
   - Если краш — вернись в Unity, добавь try-catch в скрипты.  
4. Поделись: Отправь .exe другу для фидбека.  

**Ура!** Шутер собран и сбалансирован — готов к бою!  
*Ссылка на помощь*: [Тестирование Билдов](https://docs.unity3d.com/Manual/testing.html).
