# 🚀 Создание и Запуск Проекта Топ-Даун Шутера: Твой Первый Уровень!

Привет, стрелок! 💥 Теперь, когда Unity установлен, давай создадим **проект для твоего топ-даун шутера в 3D** — как в старых аркадах, где герой бегает сверху и палит во врагов. Всё просто: следуй шагам, как по карте сокровищ. Мы настроим базовую сцену с ареной, камерой сверху и тестовым объектом. Время: 5–10 минут.  

**Что тебе понадобится?**  
- Unity Hub и Editor [из предыдущей главы](./Install.md).  
- Твоя идея: Представь арену как квадратную платформу с препятствиями.  

**Предупреждение**: Сохраняй проект на диске с много места (минимум 1 ГБ). Если что-то зависнет — закрой и открой заново.  

Готов зарядить бластер? По шагам! 📝

## Шаг 1: Открой Unity Hub и Создай Новый Проект 🆕
Unity Hub — твой "гараж" для игр.  

1. Запусти **Unity Hub** (иконка на рабочем столе или в меню).  
2. Войди в аккаунт: Кликни **"Sign In"** и введи Unity ID (email + пароль).  
3. Кликни **"New Project"** (большая кнопка в центре или в меню "File > New Project").  
4. Выбери шаблон:  
   - Найди **"3D Core"** (идеально для 3D-шутера — базовая физика и графика).  
   - Кликни на него.  
5. Настрой проект:  
   - **Project Name**: "MyTopDownShooter" (или "LaserArena2025").  
   - **Location**: Выбери папку на диске (например, Документы/UnityProjects). Не на системном диске!  
   - Кликни **"Create"**.  
6. Жди: Unity Editor откроется автоматически (первый раз может загрузить ассеты 1–2 мин).  

**Готово!** Ты в редакторе — увидишь серый фон с 3D-кубом.  
*Ссылка на помощь*: [Создание Проекта](https://docs.unity3d.com/Manual/GettingStartedCreatingNewProject.html).  

## Шаг 2: Познакомься с Интерфейсом Editor — Твоя Командная Панель 🎛️
Перед запуском разберёмся, где что.  

1. **Hierarchy** (слева): Список объектов в сцене (как инвентарь). Увидишь "Main Camera" и "Directional Light".  
2. **Scene View** (центр): 3D-мир — двигай мышкой (Alt + левая кнопка — вращение, правая — панорама).  
3. **Game View** (рядом с Scene): Как видит игрок (кнопка "Play" запустит здесь).  
4. **Project** (внизу): Твои файлы (скрипты, модели).  
5. **Inspector** (справа): Настройки выбранного объекта (позиция, цвет).  
6. **Toolbar** (сверху): Кнопки Play/Pause/Stop для теста.  

**Совет**: Если панели потерялись — иди в меню **Window >** и верни (например, Window > General > Hierarchy).  
*Ссылка на помощь*: [Обзор Интерфейса](https://docs.unity3d.com/Manual/UnityOverview.html).  

## Шаг 3: Настрой Базовую Сцену для Топ-Даун Шутера — Арена и Камера 🎯
Давай создадим арену: плоскую платформу и камеру сверху.  

1. **Создай Пол (Арена)**:  
   - В Hierarchy правой кнопкой → **3D Object > Plane**.  
   - Выбери Plane в Hierarchy.  
   - В Inspector: Scale X=10, Y=1, Z=10 (большая платформа).  
   - Position: X=0, Y=0, Z=0 (центр).  

2. **Настрой Камеру для Вида Сверху**:  
   - Выбери **Main Camera** в Hierarchy.  
   - В Inspector > Transform: Position Y=15 (подними вверх), Rotation X=90 (поверни вниз).  
   - В Camera компоненте: Projection=Perspective (3D-эффект).  

3. **Добавь Тестовый Объект (Герой-Прототип)**:  
   - Правой кнопкой в Hierarchy → **3D Object > Capsule** (как персонаж).  
   - В Inspector: Position Y=0.5 (на пол), Scale=0.5 (маленький).  
   - Добавь компонент: Кликни **"Add Component"** > Physics > **Rigidbody** (для гравитации).  

**Готово!** Сцена готова: камера смотрит сверху на платформу и капсулу.  
*Ссылка на помощь*: [Работа с Объектами](https://docs.unity3d.com/Manual/CreatingGameObjects.html).  

## Шаг 4: Запусти и Протестируй — Первый "Шот"! ▶️
Время проверить, жив ли проект.  

1. Кликни **Play** (треугольник сверху) — мир оживёт!  
2. В Game View: Камера показывает арену сверху. Капсула упадёт на пол (благодаря Rigidbody).  
3. Двигайся: Пока ничего не двигается — это нормально (добавим в уроке 3).  
4. Кликни **Stop** (квадрат), чтобы вернуться в редактор.  
5. Сохрани: **File > Save Scene As** → Назови "ArenaScene" в папке Scenes.  

**Ура!** Проект запущен. Если чёрный экран — проверь Position камеры.  
*Ссылка на помощь*: [Режим Play](https://docs.unity3d.com/Manual/GameView.html).
