# 🌍 Урок 1: Базовая Арена — Платформа и Вид Сверху

Привет, будущий архивист битв! 💥 В этом уроке мы создадим **базовую арену для твоего топ-даун шутера**: простую платформу как пол арены, камеру с видом сверху (как в классических аркадах) и тестовый объект-герой. Это фундамент — без него ни стрельбы, ни врагов! Всё делаем в одной сцене, которая будет расти. Время: 10–15 минут.  

**Что тебе понадобится?**  
- Открытый проект из предыдущей главы ("MyTopDownShooter").  
- Мышь для навигации в Scene View.  

**Предупреждение**: Если сцена пустая — создай новую: File > New Scene. Сохраняй часто (Ctrl+S)!  

Готов построить арену? По шагам, как по кирпичикам! 📝

## Шаг 1: Создай Платформу — Основу Арены 🏗️
Арена — это плоский пол, где будет происходить экшн.  

1. В **Hierarchy** (слева) правой кнопкой мыши → **3D Object > Plane**.  
2. Выбери новый Plane в Hierarchy (он появится как "Plane").  
3. В **Inspector** (справа):  
   - В компоненте **Transform**:  
     - Position: X=0, Y=0, Z=0 (центр мира).  
     - Scale: X=20, Y=1, Z=20 (большая квадратная платформа).  
4. Чтобы пол не был серым:  
   - В Project (внизу) найди папку Materials → Правой кнопкой → **Create > Material**.  
   - Назови "ArenaFloor", перетащи на Plane.  
   - В Inspector материала: Albedo — выбери цвет (зелёный для травы или серый для металла).  

**Готово!** У тебя квадратная арена. В Scene View зумь колёсиком мыши.  
*Ссылка на помощь*: [Создание Примитивов](https://docs.unity3d.com/Manual/Primitive-GameObjects.html).  

## Шаг 2: Настрой Камеру для Топ-Даун Вида — Взгляд Сверху 👁️
В шутере камера смотрит сверху, чтобы видеть всё поле.  

1. В Hierarchy найди и выбери **Main Camera**.  
2. В Inspector > **Transform**:  
   - Position: X=0, Y=20, Z=0 (подними высоко над ареной).  
   - Rotation: X=90, Y=0, Z=0 (поверни строго вниз).  
3. В компоненте **Camera** (ниже Transform):  
   - Field of View: 60 (стандартно, для обзора).  
   - Clear Flags: Skybox (небольшой фон неба).  
4. Переключись на **Game View** (вкладка рядом с Scene): Здесь будет вид игрока.  

**Готово!** Камера смотрит на арену сверху, как в старом аркадном автомате.  
*Ссылка на помощь*: [Настройка Камеры](https://docs.unity3d.com/Manual/class-Camera.html).  

## Шаг 3: Добавь Прототип Героя — Тестовый Объект на Арене 🧑‍🚀
Пока простой капсула — наш "стрелок".  

1. В Hierarchy правой кнопкой → **3D Object > Capsule**.  
2. Выбери Capsule в Hierarchy.  
3. В Inspector > Transform:  
   - Position: X=0, Y=1, Z=0 (чуть над полом).  
   - Scale: X=0.5, Y=1, Z=0.5 (компактный герой).  
4. Добавь физику: Кликни **"Add Component"** (внизу Inspector) → **Physics > Rigidbody**.  
   - В Rigidbody: Use Gravity = On (чтобы не летал).  
5. Сделай цветным: Создай Material (как в Шаге 1), назови "HeroMat", цвет синий, перетащи на Capsule.  

**Готово!** Герой стоит на арене.  
*Ссылка на помощь*: [Rigidbody Компонент](https://docs.unity3d.com/Manual/class-Rigidbody.html).  

## Шаг 4: Сохрани и Протестируй — Первый Взгляд на Арены ▶️
Проверим, как выглядит битва.  

1. Сохрани сцену: **File > Save As** → Назови "Level1_Arena" в папке Scenes (в Project).  
2. Кликни **Play** (треугольник сверху).  
3. В Game View: Видишь арену сверху? Капсула на месте?  
4. Кликни **Stop** (квадрат). Если камера не смотрит — вернись к Шагу 2.  

**Ура!** Базовая арена готова — сердце твоего шутера.  
*Ссылка на помощь*: [Сохранение Сцен](https://docs.unity3d.com/Manual/SavingScenes.html).
