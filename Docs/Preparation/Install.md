# 🛠️ Установка Unity Hub и Unity Editor: Шаг за Шагом для Новичков

Привет! 🚀 Эта глава — твой первый шаг в мир геймдева. Мы установим **Unity Hub** (центр управления проектами) и **Unity Editor** (сам редактор для создания игр). Всё просто, как собрать Lego: следуй номерам, кликай кнопки и не торопись. Если что-то не так — перезагрузи компьютер или спроси у взрослого. Время: 10–20 минут.  

**Что тебе понадобится?**  
- Компьютер с Windows, Mac или Linux (M1+ для Mac).  
- Интернет (для скачивания).  
- Минимум 4 ГБ RAM и 10 ГБ места на диске.  

**Предупреждение**: Если у тебя старый компьютер, проверь [системные требования Unity](https://docs.unity3d.com/Manual/system-requirements.html).  

Готов? Давай по шагам! 📝

## Шаг 1: Создай Аккаунт Unity ID (Если Нет) 👤
Unity требует аккаунт для скачивания — это бесплатно и быстро.  

1. Иди на [unity.com](https://unity.com) в браузере (Chrome или Firefox).  
2. Кликни **"Get Started"** или **"Sign Up"** вверху справа.  
3. Заполни форму:  
   - Email (твой почтовый ящик).  
   - Пароль (придумай сильный, запиши!).  
   - Имя и фамилия (можно псевдоним).  
4. Кликни **"Create Account"**.  
5. Проверь почту: кликни на письмо от Unity для подтверждения.  

**Готово!** Теперь ты официальный геймдев. 😎  
*Ссылка на помощь*: [Unity ID Guide](https://docs.unity3d.com/Manual/UnityID.html).  

## Шаг 2: Скачай и Установи Unity Hub 📥
Unity Hub — это "диспетчер" для Editor'ов.  

1. Залогинься на [unity.com](https://unity.com) с твоим Unity ID.  
2. Кликни **"Download Unity Hub"** (кнопка в центре или в меню).  
3. Скачай файл:  
   - Windows: `.exe` (около 100 МБ).  
   - Mac: `.dmg`.  
   - Linux: `.AppImage` (если нужно).  
4. Запусти скачанный файл:  
   - Windows: Двойной клик → "Install".  
   - Mac: Перетащи в Applications.  
   - Linux: `chmod +x UnityHub.AppImage && ./UnityHub.AppImage`.  
5. При первом запуске:  
   - Введи Unity ID и пароль.  
   - Разреши доступ (если спросит).  

**Готово!** Hub открыт — увидишь главное окно.  
*Ссылка на помощь*: [Unity Hub Download](https://unity.com/download) и [Installation Guide](https://docs.unity3d.com/Manual/GettingStartedInstallingHub.html).  

## Шаг 3: Установи Unity Editor Через Hub 🎮
Теперь добавим Editor — это программа для создания игр. Рекомендуем версию **2022.3 LTS** (стабильная, для начинающих).  

1. Открой Unity Hub.  
2. Кликни вкладку **"Installs"** (слева).  
3. Кликни **"Add"** (синяя кнопка) или **"Install Editor"**.  
4. Выбери версию:  
   - Найди **2022.3.x LTS** (LTS = Long Term Support, надёжная).  
   - Кликни **"Install"**.  
5. Выбери модули (добавки):  
   - **Windows Build Support** (если Windows).  
   - **WebGL Build Support** (для браузерных игр).  
   - **Android Build Support** (если хочешь мобильные).  
   - Для начинающих: оставь базовые, не всё сразу!  
6. Кликни **"Next"** и жди (скачивание 2–5 ГБ, 10–30 мин).  
7. Когда готово: увидишь версию в списке Installs.  

**Готово!** Editor установлен.  
*Ссылка на помощь*: [Editor Installation](https://docs.unity3d.com/Manual/GettingStartedInstalling.html).  

## Шаг 4: Проверь Установку — Первый Запуск ✅
Давай убедимся, что всё работает.  

1. В Unity Hub кликни **"New Project"** (кнопка в центре).  
2. Выбери шаблон: **3D Core** (для нашего шутера).  
3. Назови проект: "MyShooter" (или что хочешь).  
4. Кликни **"Create Project"**.  
5. Откроется Editor: увидишь Scene View, Hierarchy и Project панели.  
6. Кликни **Play** (треугольник сверху) — ничего не сломается! Нажми снова, чтобы остановить.  

**Ура!** Ты в Unity. Если ошибка — перезапусти Hub или проверь интернет.  
*Ссылка на помощь*: [First Project](https://docs.unity3d.com/Manual/GettingStartedCreatingNewProject.html).
