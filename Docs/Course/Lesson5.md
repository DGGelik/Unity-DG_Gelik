# 📝 Урок 5: Концепция Шутера — GDD с Врагами и Механиками Стрельбы

Привет, стратег битвы! 📝 В этом уроке мы создадим **GDD (Game Design Document)** — "дневник" твоего топ-даун шутера: опишем общую концепцию, механики стрельбы (пули, перезарядка) и врагов (простые боты). Это не код, а план — чтобы игра была coherentной и весёлой. GDD поможет в будущих уроках. Всё в Google Docs или текстовом файле, плюс базовый прототип в Unity. Время: 25–35 минут.  

**Что тебе понадобится?**  
- Открытый проект "MyTopDownShooter" с HUD из Урока 4.  
- Текстовый редактор (Notepad++ или Google Docs) для GDD.  

**Предупреждение**: GDD — это черновик, меняй по ходу! Сохрани как PDF для портфолио.  

Готов спроектировать хаос? По шагам, как по чертежу! 📝

## Шаг 1: Создай Шаблон GDD — Основу Документа 📄
GDD — это структура: обзор, механики, враги.  

1. Открой Google Docs (docs.google.com) или текстовый файл на компе. Назови "MEGA_Shooter_GDD".  
2. Добавь заголовок: **MEGA Shooter: Top-Down 3D Action**.  
3. Разделы (напиши по 2–3 предложения):  
   - **Обзор**: "Игра — динамичный топ-даун шутер в 3D, где игрок управляет героем на арене, стреляет в волны врагов, собирает power-ups. Цель: выжить 10 волн и набрать 1000 очков."  
   - **Целевая Аудитория**: "Подростки 13–15 лет, любители аркад как Geometry Wars."  
   - **Платформа**: "PC/WebGL, Unity 2022.3."  
4. Сохрани как .docx или экспортируй в PDF.  

**Готово!** База GDD — твой "мануал" для игры.  
*Ссылка на помощь*: [Пример GDD](https://docs.unity3d.com/Manual/GameDesign.html).  

## Шаг 2: Опиши Механики Стрельбы — Как Герой Палит 🔫
Стрельба — сердце шутера: клик мыши для выстрела.  

1. В GDD добавь раздел **Core Mechanics > Shooting**.  
2. Опиши:  
   - "Герой стреляет лазерными пулями по клику мыши (Raycast от позиции к курсору). Скорострельность: 5 выстр/сек, урон: 10 HP за пулю."  
   - "Перезарядка: 30 патронов, восстанавливается со временем (1/сек) или power-up. Анимация: вспышка на дуле."  
   - "Улучшения: Двойной огонь после 500 очков."  
3. В Unity прототип: В скрипте PlayerMovement добавь (открой и вставь в Update()):  
   ```
   if (Input.GetMouseButtonDown(0))  // Левый клик
   {
       // Простой выстрел: Создай prefab пули позже
       Debug.Log("Bang!");  // Тест в Console
   }
   ```  
4. Сохрани скрипт и протестируй в Play (кликни — увидишь сообщение).  

**Готово!** Стрельба описана и базово прототипирована.  
*Ссылка на помощь*: [Input для Мыши](https://docs.unity3d.com/ScriptReference/Input.GetMouseButtonDown.html).  

## Шаг 3: Добавь Врагов в GDD — Кто Твои Противники 👾
Враги — волны ботов, которые двигаются к герою.  

1. В GDD добавь раздел **Enemies and AI**.  
2. Опиши 3 типа:  
   - "Basic Drone: Медленный, 50 HP, двигается прямо к игроку. Дроп: +10 очков."  
   - "Fast Shooter: Быстрый, стреляет редко, 30 HP. Дроп: +5 ammo."  
   - "Boss Wave: 100 HP, следует за игроком, спавнится на 5-й волне."  
3. В Unity: Создай prefab врага — Дублируй Capsule, назови "EnemyPrefab", добавь простой скрипт (Create > C# Script "EnemyAI"):  
   ```
   using UnityEngine;

   public class EnemyAI : MonoBehaviour
   {
       public Transform player;
       public float speed = 2f;

       void Update()
       {
           if (player != null)
           {
               Vector3 direction = (player.position - transform.position).normalized;
               transform.Translate(direction * speed * Time.deltaTime);
           }
       }
   }
   ```  
4. Прикрепи к EnemyPrefab, перетащи player (героя) в поле.  

**Готово!** Враги спланированы и базово двигаются (спавн позже).  
*Ссылка на помощь*: [Простой AI](https://docs.unity3d.com/Manual/NavMeshAgent.html).  

## Шаг 4: Сохрани GDD и Прототип, Протестируй Концепцию ▶️
Интегрируем план в игру.  

1. Сохрани GDD: Экспорт в PDF, добавь в проект (перетащи в Assets > Docs).  
2. В Unity сохрани сцену: **File > Save**.  
3. Кликни **Play**: Двигай героя (WASD), кликай для "выстрела" (Console покажет). Добавь врага в Hierarchy — он пойдёт к герою!  
4. Кликни **Stop**. Если AI не работает — проверь ссылку на player.  

**Ура!** Концепция живая — GDD ведёт к полной игре.  
*Ссылка на помощь*: [Документирование в Unity](https://docs.unity3d.com/Manual/AssetBundles.html).
