# 🎨 Урок 2: Дизайн Уровня — Материалы и Текстуры Арены

Привет, дизайнер хаоса! 🎨 В этом уроке мы превратим твою базовую арену из Урока 1 в стильную платформу для перестрелки: добавим материалы (цвета, блеск) и текстуры (реалистичные поверхности, как металл или камень). Арена станет выглядеть как настоящая арена из аркадного шутера — с полом, стенами и декором. Всё в одной сцене, шаг за шагом. Время: 15–20 минут.  

**Что тебе понадобится?**  
- Открытый проект "MyTopDownShooter" с ареной из Урока 1.  
- Мышь для выбора в Project панели.  

**Предупреждение**: Если текстуры не загружаются — проверь интернет для Asset Store. Сохраняй сцену перед экспериментами!  

Готов окрасить битву? По шагам, как по палитре! 📝

## Шаг 1: Создай и Настрой Материалы для Пола — Базовый Цвет и Блеск 🟫
Материалы — это "краска" для объектов, чтобы они не были серыми.  

1. В **Project** (внизу) найди папку Materials (если нет — создай: правой кнопкой на Assets > Create > Folder).  
2. В Materials правой кнопкой → **Create > Material**. Назови "FloorMat".  
3. Перетащи "FloorMat" на Plane (арену) из Hierarchy.  
4. В Inspector материала:  
   - **Albedo**: Кликни кружок — выбери цвет (тёмно-серый для бетона или коричневый для земли).  
   - **Metallic**: 0.2 (немного металла для блеска).  
   - **Smoothness**: 0.5 (средний глянец).  

**Готово!** Пол теперь не скучный — проверь в Scene View.  
*Ссылка на помощь*: [Материалы в Unity](https://docs.unity3d.com/Manual/StandardShaderMaterialParameterAlbedo.html).  

## Шаг 2: Добавь Текстуры к Материалу — Реалистичная Поверхность 🖼️
Текстуры — это "обои" для материалов, чтобы пол выглядел как настоящий.  

1. Скачай бесплатную текстуру: Открой Unity Asset Store (Window > Asset Store) и найди "free textures" (например, "Ground Texture Pack").  
2. Импортируй: Кликни "Download" > "Import" (или перетащи PNG/JPG из браузера в Project > Textures).  
3. В Project создай папку Textures (если нет). Перетащи текстуру туда.  
4. Выбери "FloorMat" в Project. В Inspector:  
   - Albedo → Кликни кружок → Выбери текстуру (например, "concrete.jpg").  
   - Текстура наложится на пол — настрой Tiling (X=5, Y=5) для повторения.  

**Готово!** Пол теперь с текстурой, как в игре. Зумь в Scene View для проверки.  
*Ссылка на помощь*: [Импорт Текстур](https://docs.unity3d.com/Manual/ImportingTextures.html).  

## Шаг 3: Добавь Стены и Декор — Границы Арены 🧱
Чтобы арена не была пустой, добавим стены и препятствия.  

1. Создай стену: Правой кнопкой в Hierarchy → **3D Object > Cube**. Назови "Wall".  
2. В Inspector > Transform:  
   - Position: X=0, Y=0.5, Z=10 (у края арены).  
   - Scale: X=20, Y=1, Z=0.2 (длинная тонкая стена).  
3. Создай материал "WallMat" (как в Шаге 1), цвет красный, перетащи на Wall.  
4. Дублируй: Выбери Wall → Правой кнопкой > Duplicate. Повтори для 4 стен (Z=-10, X=10, X=-10).  
5. Добавь декор: **3D Object > Cylinder** как колонну (Scale=0.5, Position случайно на арене).  

**Готово!** Арена с границами — герой не убежит!  
*Ссылка на помощь*: [Создание Кубов и Масштабирование](https://docs.unity3d.com/Manual/class-Cube.html).  

## Шаг 4: Сохрани и Протестируй — Визуальный Осмотр Арены ▶️
Давай посмотрим, как выглядит дизайн.  

1. Сохрани сцену: **File > Save** (или Ctrl+S).  
2. Кликни **Play**.  
3. В Game View: Видишь текстурированный пол, стены и камеру сверху?  
4. Кликни **Stop**. Если текстуры размыты — вернись к Шагу 2 и настрой Tiling.  

**Ура!** Уровень готов к движению — арена выглядит эпично.  
*Ссылка на помощь*: [Тестирование в Play Mode](https://docs.unity3d.com/Manual/GameView.html).
