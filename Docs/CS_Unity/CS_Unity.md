# 🎮 UnityCSQuest: Полный Курс по C# в Unity для Новичков (13–15 лет) 🎮

**Привет, юный создатель игр!** 💻  
Добро пожаловать в *UnityCSQuest* — взрывной курс для подростков (13–15 лет), где ты научишься программировать на C# в Unity с нуля! Мы разберём **всё**, что нужно для твоего топ-даун шутера (*UnityTopDownShooterQuest*): от первых строк кода до крутых механик. Каждый урок — это мини-квест с объяснением "что это?", "зачем нужно?" и заданиями, где ты сразу видишь результат в игре. Пишешь код — и твой герой бегает, стреляет, а враги взрываются! Никакой скучной теории — только практика и экшн!

**Зачем это нужно?** Скрипты на C# — это как заклинания, которые оживляют игру. Они заставляют объекты двигаться, реагировать на клавиши, считать очки. Этот курс покрывает **все аспекты C# в Unity**, чтобы ты мог создать любую механику для своего шутера: от движения до боссов и сохранений.

**Требования:**  
- Unity 2022.3+ LTS (установи по [гайду](../Preparation/Install.md)).  
- Проект шутера ([Создание Проекта](../Preparation/CreateRun.md)).  
- Текстовый редактор (Visual Studio или VS Code, идёт с Unity).  

**Совет:** Создавай скрипты в папке Assets (правой кнопкой > Create > C# Script). После каждого урока жми Play (▶️) и смотри изменения в игре. Ошибки? Открой Console (Window > General > Console).  

**Готов покорять код? Листай оглавление!** 📖🔥
