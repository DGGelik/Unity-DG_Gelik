# Полный Гайд по Скриптам в Unity: От Абсолютного Нуля для Начинающих (13–15 лет)

**Привет, юный геймдизайнер!** 🚀  
Если ты никогда не писал код и даже не знаешь, что такое "скрипт", то этот гайд — для тебя! Мы создадим скрипты на C# (это язык программирования для Unity) шаг за шагом, как в игре: от простого уровня к сложному. Каждый шаг — это мини-урок с объяснением "что это?", "зачем нужно?" и заданием, где ты сам попробуешь. Ты увидишь изменения в своей игре сразу — это мотивирует!

Представь: твоя игра — это как робот, а скрипты — команды, которые говорят роботу, что делать. Без скриптов герой не пошевелится, пули не полетят, а враги не атакуют. Мы будем использовать примеры из твоего топ-даун шутера (из *UnityTopDownShooterQuest*). Если у тебя ещё нет проекта, начни с [Установка Unity](./Docs/Preparation/Install.md) и [Создание Проекта](./Docs/Preparation/CreateRun.md).

**Важные советы перед стартом:**  
- Unity — это программа для создания игр.  
- C# — простой язык, как английский, но для компьютера.  
- Скрипт — это файл с командами (расширение .cs).  
- Ты будешь работать в "Assets" папке Unity.  
- После изменений в скрипте жми Play (▶️) в Unity, чтобы увидеть, что происходит. Если ошибка — смотри в Console (Window > General > Console).  
- Делай маленькие изменения и тестируй часто!  

Гайд разделён на уровни, как в игре. Каждый уровень добавляет что-то новое. Закончи один — переходи к следующему. В конце — задания для практики в твоём шутере.

## Уровень 1: Что такое Скрипт? Первый "Привет" от Твоей Игры  
**Что это?** Скрипт — это текст с инструкциями для Unity. Как рецепт: "возьми ингредиенты, смешай — получи торт". В игре скрипт говорит: "герой, беги!" или "пуля, лети!".  

**Зачем нужно?** Без скриптов игра — просто картинка. Скрипты делают всё живым: движение, звуки, очки.  

**Шаг за шагом:**  
1. Открой свой проект в Unity (если нет — создай новый по [гайду](./Docs/Preparation/CreateRun.md)).  
2. В окне Project (внизу) найди папку Assets. Правой кнопкой мыши кликни внутри Assets > Create > C# Script.  
3. Назови скрипт "MyFirstScript" (без пробелов, английскими буквами).  
4. Дважды кликни на файл — откроется редактор кода (Visual Studio или VS Code).  
5. В скрипте ты увидишь готовый шаблон:  
   ```csharp
   using System.Collections;
   using System.Collections.Generic;
   using UnityEngine;

   public class MyFirstScript : MonoBehaviour
   {
       // Start is called before the first frame update
       void Start()
       {
           
       }

       // Update is called once per frame
       void Update()
       {
           
       }
   }
   ```  
   - **using:** Это как "импорт" инструментов. UnityEngine — основной для игр.  
   - **public class MyFirstScript : MonoBehaviour:** Название скрипта. MonoBehaviour — значит, это для Unity.  
   - **void Start():** Функция, которая запускается один раз, когда игра начинается.  
   - **void Update():** Запускается каждый кадр (много раз в секунду), для постоянных действий.  

6. Добавь в Start() эту строку:  
   ```csharp
   Debug.Log("Привет, это мой первый скрипт!");
   ```  
   Теперь Start() выглядит так:  
   ```csharp
   void Start()
   {
       Debug.Log("Привет, это мой первый скрипт!");
   }
   ```  

7. Сохрани файл (Ctrl+S). Вернись в Unity.  
8. Создай пустой GameObject: В Hierarchy (слева) правой кнопкой > Create Empty. Назови "TestObject".  
9. Перетащи скрипт MyFirstScript из Assets на TestObject в Hierarchy (или в Inspector справа Add Component > Scripts > MyFirstScript).  
10. Нажми Play (▶️ вверху). В Console увидишь сообщение "Привет, это мой первый скрипт!".  

**Что ты увидел?** Скриプト "заговорил" через консоль. Это значит, код работает!  

**Задание для практики:** Измени сообщение на "Я готов к бою!" и протестируй. Добавь вторую строку Debug.Log("Моя игра оживает!");.

## Уровень 2: Переменные — Хранение Секретов Игры  
**Что это?** Переменные — как коробки, где хранишь числа, текст или правду/ложь. Например, здоровье героя или скорость.  

**Зачем нужно?** Чтобы игра помнила вещи: сколько очков, жив ли герой. Без них всё статично.  

**Шаг за шагом:**  
1. Открой MyFirstScript.  
2. Над Start() добавь переменные:  
   ```csharp
   public int health = 100;  // Здоровье героя
   public string playerName = "SuperHero";  // Имя
   ```  
   - **int:** Для целых чисел.  
   - **string:** Для текста.  
   - **public:** Видно в Inspector Unity — можно менять без кода!  

3. В Start() добавь:  
   ```csharp
   Debug.Log("Имя: " + playerName + ", Здоровье: " + health);
   ```  

4. Сохрани, вернись в Unity. В Inspector TestObject увидишь поля Health и Player Name. Измени health на 50.  
5. Play — в Console: "Имя: SuperHero, Здоровье: 50".  

**Что ты увидел?** Переменные хранят данные, и ты их меняешь в Unity!  

**Задание:** Добавь float speed = 5.0f; (для скорости, 'f' — float). Выведи в Log. Измени в Inspector и протестируй.

## Уровень 3: Функции и Update() — Делаем Движение  
**Что это?** Функции — группы команд. Start() — один раз, Update() — постоянно.  

**Зачем нужно?** Для действий: движение каждый кадр.  

**Шаг за шагом:**  
1. Создай новый скрипт "PlayerMovement".  
2. Добавь:  
   ```csharp
   public float speed = 5.0f;

   void Update()
   {
       float moveX = Input.GetAxis("Horizontal");  // Лево/право (A/D)
       transform.Translate(moveX * speed * Time.deltaTime, 0, 0);  // Движение
   }
   ```  
   - **Input.GetAxis:** Читает клавиши.  
   - **transform.Translate:** Двигает объект.  
   - **Time.deltaTime:** Делает скорость ровной.  

3. Прикрепи к кубу или sphere (создай в сцене: правой кнопкой в Hierarchy > 3D Object > Cube).  
4. Play, жми A/D — куб двигается!  

**Что ты увидел?** Объект оживает от кода!  

**Задание:** Добавь движение по Vertical (W/S). Тестируй в топ-даун камере (см. Урок 1).

## Уровень 4: Условные Операторы — Решения в Игре  
**Что это?** If — проверка: "если здоровье 0, то умри".  

**Зачем нужно?** Для логики: если нажата кнопка, стрелять.  

**Шаг за шагом:**  
1. В PlayerMovement добавь в Update():  
   ```csharp
   if (Input.GetKeyDown(KeyCode.Space))
   {
       Debug.Log("Выстрел!");
   }
   ```  
2. Play, жми Space — сообщение в Console.  

**Что ты увидел?** Код реагирует на действия!  

**Задание:** Добавь if (health <= 0) { Debug.Log("Игра окончена!"); } в отдельный скрипт.

## Уровень 5: Корутины — Задержки и Таймеры  
**Что это?** Корутины — функции с паузами, как "жди 2 секунды".  

**Зачем нужно?** Для перезарядки, respawn.  

**Шаг за шагом:**  
1. Новый скрипт "ReloadWeapon".  
2. Добавь:  
   ```csharp
   void Update()
   {
       if (Input.GetKeyDown(KeyCode.R))
       {
           StartCoroutine(Reload());
       }
   }

   IEnumerator Reload()
   {
       Debug.Log("Перезарядка...");
       yield return new WaitForSeconds(2f);
       Debug.Log("Готов!");
   }
   ```  
3. Прикрепи, Play, жми R — пауза 2 секунды.  

**Что ты увидел?** Код ждёт!  

**Задание:** Сделай корутину для "взрыва" с задержкой.

## Уровень 6: События и Коллайдеры — Взаимодействия  
**Что это?** OnCollisionEnter — когда объекты сталкиваются.  

**Зачем нужно?** Для урона, сбор предметов.  

**Шаг за шагом:**  
1. Новый скрипт "DamageOnHit".  
2. Добавь:  
   ```csharp
   public int damage = 10;

   void OnCollisionEnter(Collision collision)
   {
       Debug.Log("Столкновение! Урон: " + damage);
   }
   ```  
3. Добавь коллайдеры объектам (Inspector > Add Component > Box Collider).  
4. Play, столкни объекты — сообщение.  

**Что ты увидел?** Объекты "чувствуют" друг друга!  

**Задание:** Сделай if (collision.gameObject.tag == "Enemy") { урон }.

## Уровень 7: Классы и Наследование — Организация Кода  
**Что это?** Классы — шаблоны, наследование — копирование с изменениями.  

**Зачем нужно?** Для повторного использования: базовый враг, потом босс.  

**Шаг за шагом:**  
1. Скрипт "Enemy".  
   ```csharp
   public class Enemy : MonoBehaviour
   {
       public int health = 50;

       public void TakeDamage(int dmg)
       {
           health -= dmg;
           if (health <= 0) Destroy(gameObject);
       }
   }
   ```  
2. Новый "BossEnemy":  
   ```csharp
   public class BossEnemy : Enemy
   {
       // Наследует health и TakeDamage
   }
   ```  
3. В другом скрипте вызови enemy.TakeDamage(10);.  

**Что ты увидел?** Код организован, легко добавлять.  

**Задание:** Создай класс Bullet с движением.
